# คู่มือการติดตั้งและเชื่อมต่อ Google Sheets & Google Drive
## ระบบติดตามผลการดำเนินงานและการใช้จ่ายงบประมาณ สำนักงาน กสม.

ระบบนี้ได้รับการออกแบบให้สามารถจัดเก็บข้อมูลบน **Google Sheets** และ **Google Drive** ของสำนักงาน กสม. ได้อย่างสมบูรณ์แบบ โดยมีขั้นตอนการตั้งค่าดังนี้:

---

### ขั้นตอนที่ ๑ : การสร้าง Google Sheet สำหรับเป็นฐานข้อมูล
1. เข้าใช้งานบัญชี Google Workspace ของสำนักงาน กสม.
2. สร้าง Google Sheets ใหม่ โดยตั้งชื่อไฟล์ว่า `ฐานข้อมูลระบบติดตามแผนงบประมาณ กสม. ๒๕๖๙`
3. คัดลอก **Spreadsheet ID** จากแถบ URL:
   - ตัวอย่าง URL: `https://docs.google.com/spreadsheets/d/1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms/edit`
   - ค่า Spreadsheet ID คือ: `1BxiMVs0XRA5nFMdKvBdBZjgmUUqptlbs74OgvE2upms`

---

### ขั้นตอนที่ ๒ : การติดตั้ง Google Apps Script (Backend API)
1. ในหน้า Google Sheet ที่สร้างขึ้น ไปที่เมนูด้านบน:
   - เลือก **ส่วนขยาย (Extensions)** &rarr; **Apps Script**
2. ลบโค้ดเดิมในหน้าต่าง `Code.gs` ออกทั้งหมด
3. คัดลอกโค้ดจากไฟล์ `google-apps-script/Code.gs` ในโปรเจกต์นี้ทั้งหมดไปวาง
4. กดปุ่มบันทึก (รูปแผ่นดิสก์ หรือ `Ctrl + S`)

---

### ขั้นตอนที่ ๓ : การ Deploy เป็น Web App
1. คลิกที่ปุ่มสีน้ำเงิน **การทำให้ใช้งานได้ (Deploy)** ที่มุมขวาบน &rarr; เลือก **รายการใหม่ (New deployment)**
2. คลิกที่รูปเฟืองด้านซ้าย &rarr; เลือกประเภท **เว็บแอปพลิเคชัน (Web App)**
3. กรอกรายละเอียด:
   - **คำอธิบาย (Description):** `NHRC Budget Monitoring API v1.0`
   - **เรียกใช้ในฐานะ (Execute as):** `ฉัน (Me - บัญชีผู้ดูแลระบบ)`
   - **ผู้มีสิทธิ์เข้าถึง (Who has access):** `ทุกคน (Anyone)` *(เพื่อให้เว็บแอปส่งข้อมูลมายังสคริปต์ได้)*
4. คลิกปุ่ม **การทำให้ใช้งานได้ (Deploy)**
5. หากระบบขอสิทธิ์เข้าถึงข้อมูล ให้คลิก **ให้สิทธิ์เข้าถึง (Authorize access)** และกดยืนยัน
6. คัดลอก **URL เว็บแอป (Web App URL)** ที่ได้ (ขึ้นต้นด้วย `https://script.google.com/macros/s/.../exec`)

---

### ขั้นตอนที่ ๔ : นำ URL มาใส่ในระบบ
1. ในหน้าเว็บระบบติดตามแผนและงบประมาณ กสม.
2. คลิกที่ไอคอนรูปก้อนเมฆ `☁️` บนแถบเมนูด้านบน หรือไปที่เมนู **Google Sheets & Drive** ทางซ้าย
3. วาง Web App URL ในช่อง **Google Apps Script Web App URL**
4. กดปุ่ม **บันทึกการตั้งค่า** และกด **ซิงก์ข้อมูลทันที (Sync Now)**
5. ระบบจะสร้างแผ่นงาน (Tabs) ใน Google Sheets ให้อัตโนมัติ 3 แผ่นงาน:
   - `Projects`: ตารางโครงการทั้งหมด, วงเงินจัดสรร, เบิกจ่ายจริง, ผู้รับผิดชอบ
   - `ProgressReports`: ข้อมูลรายงานผลรอบ ๒ เดือน (แบบ สนย.3)
   - `BudgetTransfers`: ประวัติการขอโอนเปลี่ยนแปลงงบประมาณตามระเบียบ ๒๕๖๖

---

### หมายเหตุความปลอดภัย
- หากยังไม่ได้ตั้งค่า Google Apps Script ระบบจะทำงานใน **โหมดออฟไลน์ (Local Database)** และบันทึกข้อมูลลงในเบราว์เซอร์ของเครื่องโดยอัตโนมัติ ข้อมูลจะไม่สูญหาย และพร้อมซิงก์ขึ้น Google Sheets เมื่อใส่ URL ทันที
