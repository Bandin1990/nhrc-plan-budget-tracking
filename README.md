# ระบบติดตามผลการดำเนินงานและการใช้จ่ายงบประมาณ สำนักงาน กสม.
## (NHRC Annual Action Plan & Budget Monitoring System)

ระบบบริหาร ติดตาม ประเมินผล และกำกับการใช้จ่ายงบประมาณตามแผนปฏิบัติการประจำปีของ **สำนักงานคณะกรรมการสิทธิมนุษยชนแห่งชาติ (สำนักงาน กสม.)**

พัฒนาขึ้นตรงตาม:
1. **ประกาศคณะกรรมการสิทธิมนุษยชนแห่งชาติ เรื่อง การแบ่งส่วนราชการภายในฯ (ฉบับที่ ๓ พ.ศ. ๒๕๖๙)**: รองรับ ๑๔ สำนัก/ส่วนราชการ และกลุ่มงานภายใน
2. **แผนปฏิบัติการประจำปีงบประมาณ พ.ศ. ๒๕๖๙**: ครอบคลุม ๔ ยุทธศาสตร์, ๖ แผนงานหลัก, และ ๒๗ โครงการเชิงยุทธศาสตร์ พร้อมรหัสกิจกรรมทางการ
3. **แบบ สนย.3**: แบบรายงานผลการปฏิบัติงานและการใช้จ่ายงบประมาณราย ๒ เดือน และรอบ ๖ เดือน
4. **ระเบียบ กสม. ว่าด้วยการงบประมาณ พ.ศ. ๒๕๖๖**: ระบบวินิจฉัยอำนาจอนุมัติการขอโอนเปลี่ยนแปลงงบประมาณ (ข้อ ๑๒, ๑๔, ๑๕, ๑๖) พร้อมพิมพ์ **บันทึกข้อความตราครุฑ (สม ๐๓๐๒/...)**
5. **UI Design System**: ถอดแบบหน้าจอ Deep Teal & Forest Green (`#0a4d44` / `#073b34`) ตามภาพต้นแบบ พร้อมโหมด Dark/Light, แถบขยาย Stepper ไทม์ไลน์โครงการ, แผนภูมิแท่งแนวนอนรายสำนัก, และตัวปรับขนาดฟอนต์ `A- 100% A+`

## ฟังก์ชันสำคัญในระบบ

- 📥 **นำเข้าและกรองโครงการจากไฟล์ Word**: รองรับทั้ง `.docx` และ `.doc` (HTML format) ระบบดึงชื่อโครงการ, สำนัก, ผู้รับผิดชอบ, วัตถุประสงค์, และตารางงบประมาณกิจกรรมให้อัตโนมัติ
- ⏱️ **บันทึกและพิมพ์แบบรายงาน สนย.3 (รอบ ๒ เดือน)**: ๖ ส่วนตามแบบราชการ จัดหน้า A4 พิมพ์และส่งออก PDF สวยงาม
- ⚖️ **ระบบขอโอนเปลี่ยนแปลงงบประมาณ (ระเบียบ ๒๕๖๖)**: วินิจฉัยอำนาจอนุมัติ (เลขาธิการ / ประธาน กสม. / กสม. / ครม.) พร้อมคำนวณยอดคงเหลือในตาราง ๗ คอลัมน์ และพิมพ์บันทึกข้อความตราครุฑ
- 🔐 **ระบบล็อกอินและสิทธิ์การเข้าถึง (Row-Level Security)**:
  - ผู้ใช้ทุกคนดูแดชบอร์ดภาพรวมและข้อมูลโครงการได้ (Read-All)
  - ผู้รับผิดชอบโครงการ (Project Owner) แก้ไข/รายงานผล/โอนงบได้ **เฉพาะโครงการที่ตนเองรับผิดชอบเท่านั้น**
  - ผู้ดูแลแผน (Admin) จัดการ เพิ่ม แก้ไข ลบ ได้ทุกโครงการ
  - มีระบบสลับบทบาททดสอบ (Role Simulator) ในตัว
- 📊 **แดชบอร์ดภาพรวมและรายโครงการ**: การ์ด KPI ๔ มิติ, กราฟแท่งแนวนอนเปรียบเทียบงบประมาณจัดสรร vs เบิกจ่ายจริง ๑๔ สำนัก, และ S-Curve
- 🖨️ **รายงานสรุปสำหรับนำเสนอผู้บริหาร (Executive Print Report)**: จัดหน้า A4 สรุปภาพรวมสำหรับนำเสนอผู้บริหารและคณะกรรมการ กสม.
- ☁️ **เชื่อมต่อ Google Sheets & Google Drive**: โครงสร้างสคริปต์ Google Apps Script (Code.gs) บันทึกและดึงข้อมูล พร้อมโหมด Local Database ทำงานออฟไลน์ได้ 100%

## วิธีเปิดใช้งานระบบ

```bash
# 1. ติดตั้งไลบรารี
npm install

# 2. เริ่มต้นเซิร์ฟเวอร์สำหรับพัฒนา
npm run dev

# 3. บิลด์สำหรับใช้งานจริง (Production Build)
npm run build
```

เปิดเบราว์เซอร์ไปที่: `http://localhost:3000`
